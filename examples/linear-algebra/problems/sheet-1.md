# Sheet 1: subspaces, span, kernel

1. Is the set of polynomials p with p(3) = 0 a subspace of P(R)? Prove or give a counterexample.
2. Show that span(v1, ..., vm) is the smallest subspace containing v1, ..., vm.
3. Let T: R^3 -> R^2 be T(x, y, z) = (x + y, y + z). Find the kernel and its dimension.
4. If T is a linear map and T(v) = T(w), what can you say about v - w?
